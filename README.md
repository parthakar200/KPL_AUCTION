# 🏏 KPL Auction System

A full-stack cricket auction platform that enables administrators to manage players, teams, and auction activities through an intuitive and responsive web interface.

## 🌐 Live Demo

https://kpl-auction-seven.vercel.app

---

## 🚀 Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Axios

### Backend
- Node.js
- Express.js

### Database
- Supabase (PostgreSQL)

### Deployment
- Vercel (Frontend Hosting)
- Render (Backend Hosting)
- Supabase (Database & Cloud Storage)

### Version Control
- Git
- GitHub

---

## ✨ Features

- Secure Authentication
- Team Management
- Player Management
- Auction System
- Team Purse Tracking
- Sold/Unsold Player Status
- Responsive User Interface
- REST API Integration
- Real-Time Data Synchronization

---

## 🏗️ System Architecture

```text
React Frontend (Vercel)
          │
          ▼
Node.js + Express API (Render)
          │
          ▼
Supabase PostgreSQL Database
```

---

## 📦 Deployment

### Frontend
Hosted on Vercel for fast global content delivery and automatic deployments from GitHub.

### Backend
Hosted on Render with REST APIs serving auction and management functionalities.

### Database
Supabase PostgreSQL database used for storing:
- Users
- Teams
- Players
- Auction Records
- Team Budgets
